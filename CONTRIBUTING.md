# Contributing

Thanks for contributing to this TOGAF diagrams library.

## Repository standards

- Add active diagrams under `docs/diagrams/<category>/`.
- Use lowercase kebab-case names (for example: `architecture-governance-model.png`).
- Move superseded versions to `archive/`.
- Keep links in both `README.md` and `index.md` up to date.

## Pull requests

- Use a concise PR title with the scope of change.
- Include a summary of moved, renamed, or added files.
- Verify links and image paths before submitting.
